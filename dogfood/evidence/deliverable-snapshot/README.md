# runlog-stats

A small CLI that summarizes an anoikis effort's run-log.jsonl: per-node_id/per-role
event counts and total priced cost, with unpriced events called out separately.

See [docs/usage.md](docs/usage.md) for the synopsis, a worked example, and the
unpriced-vs-total rule.

Status: implemented and tested for the anoikis-tools dogfood attestation.
